# GUI Guide

## Overview

The graphical user interface is built with Python Tkinter. The app uses a simple, modern card-based layout with a consistent visual style.

## Main screens

- Splash screen
- Home screen with registration path selection
- Patient registration screen
- Emergency registration screen
- Doctor selection screen
- Sensor collection screen
- Report preview screen

## UI notes

- The home screen shows three registration options as cards.
- The emergency path uses a red accent to indicate urgency.
- The sensor screen displays values in a readable format and uses color to mark real versus demo data.

## Customization

You can update the visual theme in `main.py` where the Tkinter style is configured.

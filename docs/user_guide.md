# User Guide

## Welcome

The Health Registration System helps staff register patients, collect sensor readings, and create reports quickly.

## Main workflow

1. Open the app.
2. Choose a registration path.
3. Register or search for the patient.
4. Select a doctor.
5. Read sensor values.
6. Review the report preview.
7. Generate the report.

## Registration options

- Existing Patient: continue with a known patient record.
- New Patient: create a fresh patient record.
- Emergency: begin an urgent registration flow.

## Tips

- Use the emergency option only for urgent patient intake.
- Make sure the required fields are filled before continuing.
- If sensor values are not available, the system can use demo fallback values.
